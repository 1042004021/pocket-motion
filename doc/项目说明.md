## 3. 技术栈

| 类别 | 技术 | 版本 |
|------|------|------|
| 设备推理 | Qualcomm QNN / HTP | 手机现有 QAIRT 2.39.0.250925；目标 HTP V79 |
| 模型 | SD1.5 + AnimateDiff-Lightning 4-step | 权重已锁定；SD1.5 UNet 源图待准备 |
| 模型转换 | ONNX / QNN EP prepare-only | host 已验证 QNN 2.52；手机需 QAIRT 2.39 |
| Python 验证环境 | `.venv`，Python 3.14.7 | torch 2.15.0+cpu、diffusers 0.43.0、onnx 1.23.2、onnxruntime-qnn 2.8.0 |
| 后续宿主 | Android Kotlin + JNI | 可行性通过后实现 |

## 8. 边界

- 本项目暂不修改 现有 Android 项目。
- 模型权重、QNN 转换产物、native 二进制和运行日志不入 Git。
- 不使用 CPU/GPU 作为视频推理兜底；若关键算子无法落到 NPU，记录阻塞并停止该路线。
- 目标不是通用视频平台，而是验证单一小型模型在目标手机上的可行性。
